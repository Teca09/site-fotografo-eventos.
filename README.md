# Site de fotografia & eventos — Kalema (projeto de demonstração)

Site fictício desenvolvido como peça de portfólio para o nicho de **eventos & criativos**
(fotógrafos, DJs, decoradores, organizadores de eventos) — o portfólio visual é o
protagonista, com texto reduzido ao mínimo.

🔗 **Demo ao vivo:** _(adicionar link do GitHub Pages depois do deploy)_

## Sobre o projeto

"Kalema Eventos & Fotografia" é um estúdio fictício de fotografia e produção de eventos
em Luanda. O objetivo do site é mostrar o trabalho de forma imediata e visual, e converter
visitas em pedidos de orçamento via WhatsApp.

## Stack

- HTML5 semântico
- CSS3 puro (sem frameworks) — variáveis CSS para o sistema de design
- JavaScript vanilla (menu mobile + header dinâmico ao scroll)
- Tipografia: [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque) + [Newsreader](https://fonts.google.com/specimen/Newsreader)

## Nota sobre as imagens

As imagens usadas são fotografias reais do [Unsplash](https://unsplash.com), livres de
direitos, relacionadas com o tema (casamentos, eventos, celebrações). Num projeto real
para cliente, seriam substituídas pelo portfólio real do fotógrafo/produtor.
